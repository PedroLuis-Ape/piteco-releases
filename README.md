# Piteco — instaladores

Este repositório guarda **só os instaladores** do app Piteco (edição pessoal), para o próprio app procurar e baixar atualizações. O código-fonte não fica aqui.

Cada versão (aba **Releases**) traz:

- `Piteco-<versão>-android-arm64.apk` — Android (celulares ARM64).
- `Piteco_<versão>_x64-setup.exe` — Windows 64 bits.
- `SHA256SUMS.txt` — a impressão digital (SHA-256) de cada arquivo. O app só instala um arquivo cuja impressão digital confere.

Os instaladores não contêm banco de dados, chaves nem dados pessoais.
