# Piteco — instaladores

## ⬇️ Baixar a versão mais nova

| Aparelho | Link fixo (sempre a versão mais nova) |
|---|---|
| 📱 **Celular Android** | **[Piteco-android.apk](https://github.com/PedroLuis-Ape/piteco-releases/releases/latest/download/Piteco-android.apk)** |
| 💻 **Windows** | **[Piteco-windows.exe](https://github.com/PedroLuis-Ape/piteco-releases/releases/latest/download/Piteco-windows.exe)** |

Esses dois links **nunca mudam** e baixam sempre a versão mais nova. A página da versão mais nova é
**[Releases → Latest](https://github.com/PedroLuis-Ape/piteco-releases/releases/latest)**. Todas as outras versões da lista são **antigas**.

## Como instalar

**Celular (Android)**
1. Abra o link do celular acima no navegador do celular e baixe (cerca de 580 MB: melhor no Wi-Fi).
2. Abra o arquivo baixado e toque em **Atualizar** (ou **Instalar**). Instala por cima: nada é apagado.
3. Daí para frente, atualize pelo próprio app: **Mais → Configurações → Atualizar o app**.

**Windows**
1. Baixe pelo link do Windows acima e abra o arquivo. Instala por cima, sem apagar nada.
2. Daí para frente, atualize pelo próprio app: **Configurações → Atualizar o app**.

## Para assistentes de IA que vão buscar a versão

- A versão mais nova é sempre a marcada como **Latest**: `https://github.com/PedroLuis-Ape/piteco-releases/releases/latest`.
- Os arquivos de nome fixo `Piteco-android.apk` e `Piteco-windows.exe` dessa versão são os que a pessoa deve baixar.
- Versões com o título terminado em **(antiga)** não devem ser indicadas.

## O que cada versão traz

- `Piteco-android.apk` e `Piteco-windows.exe` — os instaladores, com nome fixo.
- `Piteco-<versão>-android-arm64.apk` e `Piteco_<versão>_x64-setup.exe` — os mesmos arquivos, com a versão no nome. São estes que o botão "Atualizar o app" usa.
- `SHA256SUMS.txt` — a impressão digital (SHA-256) de cada arquivo. O app só instala um arquivo cuja impressão digital confere.

Este repositório guarda **só os instaladores** do app Piteco (edição pessoal). O código-fonte não fica aqui. Os instaladores não contêm banco de dados, chaves nem dados pessoais.
